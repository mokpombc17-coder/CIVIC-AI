# Pretendard GOV webfonts

These are the upstream `Regular`, `Medium`, and `Bold` WOFF2 subset files from
[`orioncactus/pretendard`](https://github.com/orioncactus/pretendard/tree/7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae/packages/pretendard-gov/dist/web/static/woff2-subset).
They are self-hosted so CIVIC.AI renders the Figma typography consistently across devices.
